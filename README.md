# 간호조무사 기출 풀기

간호조무사 국가시험 **기출문제**(2020년 하반기 ~ 2024년 하반기, 9개 회차 900문항) 학습용 웹앱.
[korean-history-quiz](https://github.com/yong426/korean-history-quiz)와 같은 구조(단일 `index.html` + `data.js` + 문항 이미지)이며,
문항은 공식 문제지 PDF를 문항 단위로 잘라낸 이미지로 보여 준다.

## 기능

- 상단 탭 3개(문제 풀이 / 복습 / 학습 기록). 세 탭이 같은 머리글·같은 탭 줄을 쓴다
- **과목(4) · 회차(9) 멀티셀렉트 + 문항 번호 범위(k~n)** → 회차·번호 순으로 순차 출제
  (기초간호학 개요 1~35 · 보건간호학 개요 36~50 · 공중보건학 개요 51~70 · 실기 71~100)
- 5지선다 즉시 채점 + 해설(핵심 주제 · 정답 근거 · 헷갈리는 오답 이유)
- **복습 탭** — 오답노트와 ★ 별표(잘 몰라서 찍은 문항)를 분리 보관, 과목 필터, 다시 풀기
- **중간 저장 & 정지** — 문제 풀기 / 오답 복습 / 별표 복습 각각 별도 슬롯, 홈에서 '이어서 풀기'
- **학습 기록** — 세션 이력, 과목별 누적 정답률, '풀어본 범위' 진행률
- **버전 자동 갱신** — `version.json`을 확인해 새 버전이면 설정·중간저장만 비우고 최신 UI로 새로고침
- 데이터는 브라우저 localStorage(키 접두어 `npq_`)에 기기별 저장. 아이패드 '홈 화면에 추가' 지원

문항이 이미지라 보기 순서 무작위는 적용할 수 없다.

## 데이터 파이프라인 (`tools/`)

| 단계 | 도구 | 비고 |
|---|---|---|
| 문항 크롭 | `extract.py <회차> <문제지.pdf>` | 텍스트 레이어가 있는 PDF. 국시원 A3 2단·HWP 변환 A4 2단 모두 처리. `img/<회차>/NN.webp`, `tools/text/<회차>.json` 생성 |
| 문항 크롭(스캔) | `extract_scan.py <회차> <스캔.pdf>` | 텍스트 레이어 없는 스캔본. 문항번호 내어쓰기 잉크 띠로 경계 검출(OCR 미사용). 2024상 |
| 정답 | `answers.py <회차> <가답안.pdf>` | 국시원 가답안 표 PDF |
| 정답(기타) | `answers_misc.py table2020 / ocr` | 마지막 쪽 정답표 형식(2020하). 2024하 가답안은 스캔이라 눈으로 옮겨 적음 |
| 해설 | `prompt_explain.md` | 회차별 서브에이전트가 `tools/text`+`tools/answers`로 `tools/exp/<회차>.json` 작성 |
| 병합 | `merge.py` | 이미지·정답·해설이 100개 모두 있는 회차만 `data.js`에 넣고 `version.json`의 `data` 갱신 |

회차 id는 `YYYY-1`(상반기) / `YYYY-2`(하반기). 문항 id는 `2022-1-17` 형식.

### 크롭 검수 요령
`extract.py`가 출력하는 **종횡비 상위/하위** 문항을 눈으로 확인한다. 인접 문항이 붙었거나 보기가 잘리면 종횡비가 튄다.
실제로 잡힌 결함: 과목 머리글 상자가 직전 문항에 붙음(머리글 정규식에 `개론` 누락), 단 구분선이 크롭에 포함,
"뒷면의 응시자 안내사항…" 줄이 푸터로 오인되어 하단 보기가 잘림, HWP 변환본 머리글 높이에 있는 우측 단 첫 줄 누락.

## 배포

`index.html`의 `APP_VERSION`과 `version.json`의 `app`을 같은 값으로 올리고, 문항이 바뀌면 `merge.py`로 `data`도 올린다.
푸시는 두 브랜치에 함께: `git push origin main main:gh-pages`
