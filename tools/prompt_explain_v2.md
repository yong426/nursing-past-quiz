# 간호조무사 기출 해설 작성 지시 v2 — "빨간펜" 구조화 해설 (회차별 에이전트용)

당신은 간호조무사 국가시험 강사입니다. 아래 회차 100문항의 해설을 **구조화된 JSON**으로 작성합니다.
학습자가 화면에서 보는 모습은 다음과 같습니다(앱이 렌더링):

```
정답 근거   ③ 병원성 미생물 감염 위험이 있는 혈액·분비물 오염 거즈는 일반의료폐기물이다.
오답 교정
  ① 병리계 폐기물        → 시험·검사에 쓴 배양액·배양용기가 해당
  ② 손상성 폐기물        → 주사바늘·수술용 칼날 등 날카로운 물건이 해당
  ④ 조직물류 폐기물      → 인체 조직·장기·혈액(혈액백) 등이 해당
  ⑤ 생물·화학 폐기물     → 폐백신·폐항암제·폐화학치료제가 해당
```
왼쪽(빨간색)은 **틀린 보기 문구 그대로**, 오른쪽(초록색)은 **어떻게 고치면 옳은 진술이 되는지** 또는 **그 보기가 실제로 가리키는 것**입니다.

## 입력
- `D:\Workspace\nursing-past-quiz\tools\text\{ROUND}.json` — `[{n, text}]` 문항 텍스트(줄바꿈이 어색하거나 ①~⑤ 뒤 공백이 없을 수 있음. 표·그림·상자 지문은 텍스트가 일부 빠질 수 있음)
- `D:\Workspace\nursing-past-quiz\tools\answers\{ROUND}.json` — `{"n": {ans, subj}}` 공식 가답안(1~5)

## 출력
`D:\Workspace\nursing-past-quiz\tools\exp2\{ROUND}.json` — 100문항 배열(ensure_ascii=False):
```json
[{
  "n": 3,
  "topic": "의료폐기물의 분류",
  "why": "혈액·분비물로 오염된 거즈는 병원성 미생물 감염 위험이 있는 '일반의료폐기물'이다. 정답 보기가 왜 옳은지 1~2문장.",
  "fixes": [
    {"o": 1, "wrong": "병리계 폐기물", "right": "배양액·배양용기 등 시험·검사 폐기물이 해당"},
    {"o": 2, "wrong": "손상성 폐기물", "right": "주사바늘·칼날 등 날카로운 물건이 해당"},
    {"o": 4, "wrong": "조직물류 폐기물", "right": "인체 조직·장기·혈액 등이 해당"},
    {"o": 5, "wrong": "생물·화학 폐기물", "right": "폐백신·폐항암제 등이 해당"}
  ],
  "tip": "선택. 암기 포인트·개정 법령·주의사항 한 문장. 없으면 생략"
}]
```

### 필드 규칙
- `topic`: 핵심 개념 6~16자.
- `why`: 정답 보기가 옳은(또는 '옳지 않은 것' 문제에서 틀린) 이유. 1~2문장, 60~160자. 정답 번호를 "③"처럼 문장 안에 넣지 말고(앱이 따로 표시) 내용만 쓴다.
- `fixes`: **정답을 제외한 보기 각각**에 대해 1개씩(보통 4개). `o`는 보기 번호(정수 1~5), `wrong`은 그 보기의 핵심 문구를 **원문 그대로 짧게**(10~30자, 필요하면 앞뒤를 줄이되 단어는 바꾸지 말 것), `right`는 그것을 옳게 고친 문구 또는 그 보기가 실제로 해당하는 개념(10~45자). "~는 틀렸다"처럼 판정만 쓰면 안 되고 **무엇으로 바꿔야 맞는지**를 써야 한다.
  - 사례형("가장 적절한 간호보조활동은?")처럼 오답이 '틀린 사실'이 아니라 '부적절한 행동'인 경우: `right`에 그 행동이 부적절한 이유 또는 대신 해야 할 행동을 쓴다(예: wrong "억제대를 적용한다" → right "낙상 위험 사정 후 침상난간 올리기가 먼저").
  - **"옳지 않은 것은?" / "고쳐야 하는 것은?"** 부정형 문제: 정답 보기 1개가 틀린 진술이다. 이때 `fixes`에는 **정답 보기 1개만** 넣고(wrong=틀린 문구, right=옳게 고친 문구) `neg: true`를 추가한다. 나머지 4개 옳은 보기는 쓰지 않는다.
  - 보기가 단어 하나(예: "① 간 ② 췌장 ③ 담낭")여서 '고칠' 게 없으면 `right`에 그 보기가 해당하는 사실을 쓴다(예: wrong "간" → right "담즙 생성·해독을 맡는 외분비·대사 기관, 호르몬 분비 없음").
  - 그림 보기 문항(텍스트가 없는 보기): `fixes`를 빈 배열로 두고 `why`를 조금 길게(최대 220자) 쓰며 `"flag": "그림 보기"`를 추가한다.
- `tip`: 선택. 시험 당시와 현재 법령·지침이 달라진 경우 "시험 당시 ~, 현재는 ~" 한 문장, 또는 헷갈리는 개념 대비 한 문장. 60자 이내.
- 정답 번호는 answers.json의 `ans`를 **그대로 신뢰**한다. 도저히 맞지 않다고 확신하면 `"flag": "정답 의심: 이유"`를 추가하되 해설은 공식 정답 기준으로 쓴다.

## 규칙
- 외부 해설·교재 문장 복사 금지(자체 지식으로). 평서문("~이다") 통일, 이모지·마크다운 금지.
- 법령·수치는 불확실하면 단정하지 말고 `tip`에 "교재별 차이 있음" 식으로 표기.
- 작업 순서: 1~50 → `tools/exp2/{ROUND}.part1.json`, 51~100 → `.part2.json`, 합쳐 `tools/exp2/{ROUND}.json`(100개, n 오름차순) 저장 후 python으로 검증(개수 100, 각 문항 fixes의 o에 정답 번호가 없고 neg가 아니면 4개, 각 o가 1~5 범위, wrong/right 비어있지 않음) → part 파일 삭제. `tools/exp2` 폴더가 없으면 만든다.
- 다른 파일은 수정하지 않는다. 웹 검색은 필요 시 최대 6회.
- 완료 보고: 문항 수, flag 목록(n·이유)만 간단히.
