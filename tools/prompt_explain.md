# 간호조무사 기출 해설 작성 지시 (회차별 에이전트용)

당신은 간호조무사 국가시험 강사입니다. 아래 회차의 기출 100문항에 대해 **핵심 주제와 해설**을 작성합니다.

## 입력
- `D:\Workspace\nursing-past-quiz\tools\text\{ROUND}.json` — `[{n, text}]` 문항 텍스트(PDF 텍스트 레이어 추출. 줄바꿈이 어색하거나 보기 기호 ①~⑤ 뒤에 공백이 없을 수 있음. 표·그림·상자 지문은 텍스트가 일부 빠질 수 있음)
- `D:\Workspace\nursing-past-quiz\tools\answers\{ROUND}.json` — `{"n": {ans, subj}}` 공식 가답안(1~5)과 과목

## 출력
`D:\Workspace\nursing-past-quiz\tools\exp\{ROUND}.json` 하나에 **100문항 전부**를 JSON 배열로 저장(ensure_ascii=False, UTF-8):
```json
[{"n": 1, "topic": "간호조무사의 직업적 태도", "exp": "해설 본문 …"}, ...]
```
- `topic`: 문항의 핵심 개념을 6~16자로 (예: "부갑상샘호르몬의 작용", "내과적 무균법 손씻기").
- `exp`: 150~320자, 2~4문장. 구조 = ①정답이 되는 이유(핵심 개념·근거) → ②헷갈리기 쉬운 오답 1~2개가 틀린 이유. 학습자가 개념을 잡도록 쓰되 장황하게 쓰지 말 것. 보기를 언급할 때는 "②"처럼 기호로.
- 정답 번호는 answers.json의 `ans`를 **그대로 신뢰**하고 그 보기가 정답인 이유를 씁니다. 도저히 정답이 맞지 않다고 확신하는 경우에만 `"flag": "이유"` 필드를 추가하고 해설은 공식 정답 기준으로 씁니다.
- 텍스트가 빠져 판단이 어려운 문항(표/그림)은 보기 텍스트와 정답으로 최대한 추론해 쓰고 `"flag": "지문 일부 누락"`을 넣습니다.

## 규칙
- 외부 해설 사이트·교재 문장을 복사하지 말고 **자체 지식으로** 작성합니다(저작권).
- 법령·수치는 시험 시행 당시와 현재가 다를 수 있음. 개정을 알고 있으면 "시험 당시 기준 ~, 현재는 ~" 한 문장으로 짚어주고, 불확실하면 단정하지 않습니다.
- 존댓말 없이 평서문("~이다", "~한다")으로 통일. 이모지·마크다운 금지.
- 작업 순서: 1~50번을 먼저 작성해 `tools/exp/{ROUND}.part1.json`으로 저장 → 51~100번을 `tools/exp/{ROUND}.part2.json` → 두 파일을 합쳐 `tools/exp/{ROUND}.json`(100개, n 오름차순)으로 저장하고 개수·JSON 유효성을 python으로 검증한 뒤 part 파일은 삭제.
- 다른 파일은 절대 수정하지 않습니다. 웹 검색은 필요 시 최대 6회.
- 완료 보고: 문항 수, flag 목록(n과 이유)만 간단히.
